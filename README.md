## 📝 Todo App (Full Stack)

A full-stack Todo application built using **React.js**, **Node.js**, **Express.js**, and **PostgreSQL**. This app allows users to manage daily tasks efficiently with features like creating, updating, deleting, and marking tasks as completed.

---

## 🚀 Features

* ✅ Create new todos
* 📋 View all todos
* ✏️ Edit/update existing todos
* ❌ Delete todos
* ✔️ Mark tasks as completed
* 🔄 Real-time UI updates

---

## 🛠️ Tech Stack

**Frontend:**

* React.js

**Backend:**

* PostgreSQL

/client → React frontend

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### 2. Setup Backend

```bash
cd backend
npm install
npm run dev
```

### 3. Setup Frontend

```bash
cd client
npm install
npm start
```

### 4. Setup Database

* Install PostgreSQL
* Create a database
* Run the SQL file provided in `/database`

---

## 🔗 API Endpoints

* GET `/todos` → Get all todos
* POST `/todos` → Create new todo
* PUT `/todos/:id` → Update todo
* DELETE `/todos/:id` → Delete todo
